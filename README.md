# Project Description

A simple program that calculates the total payment for purchasing items, including a 10% tax.  
The user inputs the quantity and the unit price, and the program outputs the total cost without decimal places.

## Features
- Input quantity and price.
- Compute total cost including 10% tax.
- Output formatted as an integer.

## Example
Input:
```
7
30000
```

Output:
```
231000
```

## Technologies
- C++
- Standard input/output

## How to Run
1. Compile the code using:
   ```
   g++ -std=c++17 main.cpp -o program
   ```
2. Run the program:
   ```
   ./program
   ```
